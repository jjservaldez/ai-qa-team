## Not covered

- Error response from the server (5xx): the browser's built-in developer tools can't force a 5xx status on the booking request without a proxy or mock tool, and the tester isn't given one. Dropped and slow networks are covered (TC-040, TC-041).
- Time-dependent rules (check-in 3:00–8:00 PM, check-out by 11:00 AM): these appear only as policy text, and no AC ties booking acceptance to the time of day. Only the "today" case (TC-029) records the execution time.
